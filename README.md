# Python Live Coding Showcase

This repository contains some commonly asked Python live coding exercises often found in technical interviews.

## Structure

Each folder contains:
- `solution-START.py`: A Python file with the function to implemented.
- `solution-END.py`: A Python file with the solution implemented.
- `README.md`: Description and instructions for the exercise.

## Exercises

1. Remove Duplicates
2. FizzBuzz
3. Reverse Words

## How to Run

```bash
cd 01_remove_duplicates
python solution-END.py
```

Repeat the same for each folder.
